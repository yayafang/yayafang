## ⭐ Highlight

### [MAIA: Test-Free Multi-Agent Instruction Adaptation for LLM Code Generation](https://github.com/yayafang/MAIA)

Self-improving code generation that **trains the prompt, not the model, and needs no unit tests**.
An Analyzer agent compares generated code with reference solutions, and an Optimizer agent turns that
feedback into a better instruction, batch by batch. At inference time it's a single LLM call.
